# Recipes

Step-by-step guides for the changes we make most often. Follow them exactly; if a recipe is wrong
or missing a step, fix the recipe in the same pull request.

| Recipe | Use when |
|---|---|
| [Work package](work-package.md) | Starting any task from `docs/milestones/` |
| [New backend app](new-backend-app.md) | Adding a new domain area (e.g. `challenges`) |
| [New endpoint](new-endpoint.md) | Adding or changing an API endpoint, backend to frontend |
| [New screen](new-screen.md) | Adding a route/screen to the PWA |
| [New migration](new-migration.md) | Changing models |
| [New Celery task](new-celery-task.md) | Background or scheduled work |
| [New ADR](new-adr.md) | Making or changing an architecture decision |
