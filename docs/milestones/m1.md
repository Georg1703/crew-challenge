# Milestone 1 · Foundations

**Dates:** 1–5 October 2026
**Goal:** the frame the whole project builds on. No game features yet, but every layer they need
exists and is proven end to end.

## Definition of done for the milestone
1. `git clone` → `make setup` → `make dev` gives a working app at `http://localhost:5173` with a
   seeded demo crew.
2. `make check` passes locally and in CI.
3. The app is live at `https://<APP_DOMAIN>` on Lightsail with HTTPS and installs as a PWA on one
   iPhone and one Android phone.
4. The owner creates the crew, invites members by link, and each member can log in and stays logged in.
5. The S3 media bucket has CORS and lifecycle rules; a 100 MB browser multipart upload succeeds.
6. Pushing to `main` deploys automatically; the database is backed up nightly to S3.
7. A cold agent can add an endpoint and a screen by following the recipes, without asking.
